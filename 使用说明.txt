小肥鱼 AI 公司 · 使用说明
====================================

这是什么
--------
一个只在自己电脑上跑的小软件：你自己建岗位（员工），把活派下去，
几个 AI 按「接力 / 并排 / 审稿」的流程干活，你在关键步骤点通过，
最后拿到一份成品（Markdown 或 Word），每一步花了多少钱都写在明面上。

没有服务器、没有账号、不上传你的东西。
员工做过的活会自动进「企业知识库」，下次干活前它们会先翻那里。

运行条件（很简单）
------------------
- Windows 10 / 11，64 位
- 需要 Edge WebView2（Win11 自带；Win10 一般也有，万一开起来是白屏，
  去 https://developer.microsoft.com/microsoft-edge/webview2/ 装一下「常青版」）
- 要能上网（连 api.deepseek.com）
- 需要一个你自己的 DeepSeek API Key（见第一步，几块钱能用很久）


第一步：准备一个 API Key（必须）
------------------------------
软件本身不含 AI，需要一个 DeepSeek 的 key 来驱动这些员工。
**key 是你自己的，费用记在你自己的账号上**，跟发软件给你的人没关系。

方式一（推荐，在软件里填）：
1. 打开软件，点右上角「🔑 Key」
2. 粘进 sk- 开头的那串，点保存 —— 立刻生效，不用重启

方式二（手工）：
1. 打开 https://platform.deepseek.com/api_keys
2. 注册 / 登录，点「创建 API Key」，复制那串 sk- 开头的东西
3. 在放本软件的文件夹里，右键 → 新建 → 文本文档
4. 把文件名改成 key.txt（连扩展名一起改，变成 key.txt 而不是 key.txt.txt）
5. 用记事本打开它，粘进去 key，保存
6. 关掉再打开软件

费用：DeepSeek 现在很便宜。普通模式一个 3000 字报告约 0.01—0.03 元；
默认开了「深度思考」，约贵 4 倍（实测 300 字约 0.03 元）。
嫌贵：启动前设环境变量 AC_DEEP=0 就回到普通模式。
别把 key 发给别人，谁拿到谁就能花你的钱。


第二步：双击
-----------
双击 小肥鱼AI公司.exe —— 直接出一个窗口，没有黑框、不开浏览器。

- 关窗口不等于关软件：它躲进右下角托盘，任务继续跑
- 要从托盘回来：双击托盘图标，或右键 →「打开小肥鱼 AI 公司」
- 真要退出：托盘右键 →「退出」
- 想两个项目并排：侧栏「+ 新建项目」右边的 ⧉ 按钮，单独开一个窗口


第三步：开始用
--------------
1. 「招募市场」→ 挑岗位招人（论文报告类会排前面），或点「自己写一个岗位」
   也可以直接写一句话，点「✨ 起草」，AI 帮你写成岗位说明书
2. 「任务」→ 派一个活：写清目标、验收标准、预算，按顺序点员工排流水线
3. 点「开始」，看它们逐句交付；带锁的那一步会停下等你点通过
4. 跑完可以「导出 Word / Markdown」；「老板看板」看全公司花了多少
5. 「企业知识库」看全公司做过的东西，搜一个词就能翻出来；也能自己存资料进去


数据在哪 / 怎么备份
------------------
在你放 exe 的同一个文件夹里：
- company.db   —— 全部员工、任务、对话、记忆、知识库（就这一个文件）
- images/      —— 出图岗生成的图片

整份拷走这两个东西 = 备份了整个公司。换电脑时把它们和 exe 放一起就行。

⚠️ 把软件发给别人时：**只发 exe（或这个压缩包）**。
   不要把你的 company.db 和 key.txt 一起发出去 ——
   前者是你的全部工作记录，后者是你的钱包。


常见问题
--------
问：Windows 弹「已保护你的电脑」，打不开？
答：点「更多信息」→「仍要运行」。这是没买代码签名证书的正常提示。

问：杀毒软件报毒？
答：PyInstaller 打的单文件 exe 常被误报，加白名单即可。源码在
    https://github.com/chen200006/xiaofeiyu-ai-company 可以自己看、自己编译。

问：双击没反应 / 开起来是白屏？
答：先看同一个文件夹里有没有 error.log；
   白屏多半是缺 WebView2 运行时（见上面「运行条件」）。

问：端口被占用？
答：它会自己往后找（8811 → 8812 …），不用你管。

问：出图失败 / 报 402？
答：出图走的是免费接口，有频控，重跑一次通常就好。

问：能几个人一起用吗？
答：不能，这是单机版。想多人共用一个知识库，得改造成服务端。

问：发给别人能用吗？
答：能，但对方要：
    1) 自己的 DeepSeek key（花他自己的钱）
    2) Windows 10/11 + WebView2
    3) 想保留自己的数据就别覆盖 company.db
    多人协作、共享知识库目前不支持。
